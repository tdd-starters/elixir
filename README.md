# Elixir TDD Starter
Simple starter for getting started with TDD in Elixir.

The file _test/elixir_tdd_starter_tests.ex_ contains one test case and a few in comments. Start by coming
up with a few test cases and add them to the lists, then implement them one at a time, test-driving the
solution forwards.

## Libraries
- _ex_parameterized_ for parametrizing tests

## Running
Tests are run by _mix_. Execute:

```shell
$ mix test
```

to run all the tests.
